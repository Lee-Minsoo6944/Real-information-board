## 짧은 확인 방법
1. 위치: https://lee-minsoo6944.github.io/t04-real-information-board/t05/checks.html 와 정보판 ② 일별 기록
2. 행동: 검사 페이지를 연다 → 맨 위 숫자를 본다 → 정보판 ② 일별 기록 표 아래 한 줄을 본다
3. 통과 모습: 초록색 10/10 PASS, 정보판에 일별 기록 n건과 "최저 … °C · 최고 … °C · 평균 … °C · 7일 중 n일 기록"
4. 안 될 때 모습: 빨간 n/10 PASS 와 FAIL 행(기대값·실제값), 또는 정보판에 "최근 7일 기록 없음"·일별 기록 0건

## AI와 나의 판단
1. AI에게 맡긴 일: 개선 기능·검사 10개·공통 상한(60분·12회) 제안, 검사 실행기와 인수인계 문서 작성, 기능 구현(A는 기간·최저·최고·평균 계산, B는 동점·단위 섞임·문구·화면 연결)과 B 결과 확인
2. 직접 판단한 일: 과제를 처음부터 다시 진행하기로 한 것, B를 A와 다른 서비스(Codex)로 정한 것, B에게 앞 대화 없이 최초 요청·브랜치·인수인계 문서만 준 것
3. AI 제안을 따르지 않은 일: 다시 시작할 때 새 기능으로 바꾸자는 AI 제안을 따르지 않고, 같은 기능("최근 7일 요약")과 같은 검사 10개로 다시 진행했다
