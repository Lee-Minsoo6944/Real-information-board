5. 다음 작업의 도구 선택 기준

기대값이 검사로 고정된 순수 계산은 어느 도구에 맡겨도 되지만, 기존 파일을 고쳐 화면에 연결하는 일은 저장소를 직접 읽고 실행해 볼 수 있는 도구에 먼저 맡기고, 통과 수가 아니라 실제 화면까지 확인한 뒤 끝낸다.

근거: 3절에서 B는 검사 10/10 이었지만 검사 밖 화면 결함이 있었고, A는 저장소에서 직접 실행·재현하며 작업했습니다. 다음에는 화면 확인 검사 한 개를 고정 검사에 넣겠습니다.
